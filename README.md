# Мельба — лендинг кондитерской

Одностраничный сайт кондитерской, специализирующейся на свадебных тортах.
Один файл `index.html` — без сборки, зависимостей и внешних скриптов.

## Что внутри

- **Три режима в одном блоке** — «Заказать торт», «Дегустация», «Доставка»
  переключаются кнопками, панель открывается под ними.
- **Форма заказа** — дата, площадка, число гостей, загрузка фото-референса,
  выбор начинки, презентация и нарезка, способ и время связи.
- **Короткая форма дегустации** — дата, количество человек, контакты.
- **Самодорисовывающийся эскиз** — линейный SVG торта: ярусы появляются
  по мере прокрутки шагов заказа.
- **Слоты под фотографии** держат пропорции будущих снимков, чтобы макет
  не поехал при замене на реальные кадры.

## Оформление

| | |
|---|---|
| Фон | айвори `#FBF9F5`, ракушка `#F4EDE7` |
| Текст | графит `#2E2A27`, абзацы `#544D47`, подписи `#6E675F` |
| Акцент | пудровая роза `#915B4A`, шампань `#9C8558` |
| Заголовки | Cormorant Garamond |
| Текст | Jost |

Контраст всех текстовых пар проверен по WCAG AA (минимум 4.5:1 для обычного
текста, 3:1 для крупного и иконок).

## Анимации

Скролл — инерционный лерп на десктопе с мышью; полоса прогресса; появление
блоков и шторки по IntersectionObserver; построчный выезд заголовков из-под
маски; дрейф карточек; параллакс героя. Кнопки — заливка снизу вверх,
магнитное притяжение к курсору, отклик на нажатие, сдвиг стрелки.

Всё это выключается при `prefers-reduced-motion: reduce`; магнитные кнопки
не включаются на тач-устройствах.

## Как открыть

Скачайте `index.html` и откройте в браузере — сборка не нужна.

## Перед публикацией

Форма пока не отправляет данные. В скрипте найдите:

```js
const ENDPOINT = '';
```

Впишите адрес обработчика — заявки пойдут на сервер. Сейчас показывается
только экран подтверждения.

Контакты, адрес студии, цены доставки и отзывы — демонстрационные,
замените на настоящие.
