# Торт по любви — лендинг кондитерской

Одностраничный сайт кондитерской, специализирующейся на свадебных тортах.
Один файл `index.html` — без сборки, зависимостей и внешних скриптов.

## Что внутри

- **Три режима в одном блоке** — «Заказать торт», «Дегустация», «Доставка»
  переключаются кнопками, панель открывается под ними.
- **Форма заказа** — дата, площадка, число гостей, загрузка фото-референса,
  выбор начинки, презентация и нарезка, способ и время связи.
- **Короткая форма дегустации** — дата, количество человек, контакты.
- **Самодорисовывающийся эскиз** — линейный SVG торта: ярусы появляются
  по мере прокрутки шагов заказа.
- **Слоты под фотографии** держат пропорции будущих снимков, чтобы макет
  не поехал при замене на реальные кадры.

## Оформление

| | |
|---|---|
| Фон | айвори `#FBF9F5`, ракушка `#F4EDE7` |
| Текст | графит `#2E2A27`, абзацы `#544D47`, подписи `#6E675F` |
| Акцент | пудровая роза `#915B4A`, шампань `#9C8558` |
| Заголовки | Cormorant Garamond |
| Текст | Jost |

Контраст всех текстовых пар проверен по WCAG AA (минимум 4.5:1 для обычного
текста, 3:1 для крупного и иконок).

## Анимации

Скролл — инерционный лерп на десктопе с мышью; полоса прогресса; появление
блоков и шторки по IntersectionObserver; построчный выезд заголовков из-под
маски; дрейф карточек; параллакс героя. Кнопки — заливка снизу вверх,
магнитное притяжение к курсору, отклик на нажатие, сдвиг стрелки.

Всё это выключается при `prefers-reduced-motion: reduce`; магнитные кнопки
не включаются на тач-устройствах.

## Как открыть

Скачайте `index.html` и откройте в браузере — сборка не нужна.

## Заявки в Telegram

Токен бота **нельзя** класть в `index.html`: страница статическая, её исходник
видит любой, а репозиторий публичный. Поэтому между сайтом и Telegram стоит
воркер из папки `telegram-worker/` — токен лежит в секретах Cloudflare.

### 1. Создайте бота

В Telegram напишите [@BotFather](https://t.me/BotFather): `/newbot`, задайте имя
и адрес. В ответ придёт токен вида `1234567890:AA...` — **никому его не
показывайте и не вставляйте в код**.

### 2. Узнайте, куда слать заявки

Напишите своему боту любое сообщение, затем откройте в браузере
(подставив свой токен):

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

Найдите `"chat":{"id":...}` — это ваш `chat_id`. Для общего чата команды
добавьте бота в группу и возьмите её id (он будет с минусом).

### 3. Поднимите воркер

```bash
npm install -g wrangler
cd telegram-worker
wrangler login
wrangler secret put TELEGRAM_BOT_TOKEN
wrangler secret put TELEGRAM_CHAT_ID
wrangler deploy
```

Токен вводится в консоли и в файлы не попадает. После `deploy` вы получите
адрес вида `https://tort-po-lyubvi-zayavki.ВАШ.workers.dev`.

### 4. Подключите к сайту

В `index.html` найдите и подставьте адрес:

```js
const ENDPOINT = '';
```

Пока строка пуста, форма работает как демонстрация: показывает подтверждение,
никуда не отправляя.

### Что уже учтено

- Если заявка не дошла — человек видит предупреждение и запасные контакты,
  а не ложное «отправлено».
- Фото-референсы уходят в тот же чат следующими сообщениями (до 6 штук).
- Скрытое поле-ловушка отсекает спам-ботов.
- `ALLOWED_ORIGINS` в `wrangler.toml` не даёт чужим сайтам слать заявки
  от вашего имени.

Контакты, адрес студии, цены доставки и отзывы — демонстрационные,
замените на настоящие.
