# Торт по любви — лендинг кондитерской

Одностраничный сайт кондитерской, специализирующейся на свадебных тортах.
Один файл `index.html` — без сборки, зависимостей и внешних скриптов.

## Что внутри

- **Три режима в одном блоке** — «Заказать торт», «Дегустация», «Доставка»
  переключаются кнопками, панель открывается под ними.
- **Форма заказа** — дата, площадка, число гостей, загрузка фото-референса,
  выбор начинки, презентация и нарезка, способ и время связи.
- **Короткая форма дегустации** — дата, количество человек, контакты.
- **Самодорисовывающийся эскиз** — линейный SVG торта: ярусы появляются
  по мере прокрутки шагов заказа.
- **Слоты под фотографии** держат пропорции будущих снимков, чтобы макет
  не поехал при замене на реальные кадры.

## Оформление

| | |
|---|---|
| Фон | айвори `#FBF9F5`, ракушка `#F4EDE7` |
| Текст | графит `#2E2A27`, абзацы `#544D47`, подписи `#6E675F` |
| Акцент | пудровая роза `#915B4A`, шампань `#9C8558` |
| Заголовки | Cormorant Garamond |
| Текст | Jost |

Контраст всех текстовых пар проверен по WCAG AA (минимум 4.5:1 для обычного
текста, 3:1 для крупного и иконок).

## Анимации

Скролл — инерционный лерп на десктопе с мышью; полоса прогресса; появление
блоков и шторки по IntersectionObserver; построчный выезд заголовков из-под
маски; дрейф карточек; параллакс героя. Кнопки — заливка снизу вверх,
магнитное притяжение к курсору, отклик на нажатие, сдвиг стрелки.

Всё это выключается при `prefers-reduced-motion: reduce`; магнитные кнопки
не включаются на тач-устройствах.

## Как открыть

Скачайте `index.html` и откройте в браузере — сборка не нужна.

## Структура

```
index.html            главная: работы, процесс, цены, формы, отзывы
checkout/             оформление заказа
demo-checkout/        имитация платёжного экрана ЮKassa (noindex)
success/  fail/       результат оплаты (noindex)
assets/               токены дизайна, стили, каталог, корзина
api/                  Cloudflare Worker: заявки, платежи, VK Callback
robots.txt sitemap.xml
```

## Магазин и оплата

Корзина хранит **только id и количество**. Сумму считает сервер по
`api/catalog.js` — всё, что пришло из браузера сверх этого, игнорируется.
Подменить цену в запросе нельзя.

Оплата пока демонстрационная: `create-payment` не ходит наружу, а
возвращает ссылку на `/demo-checkout/`. Схема повторяет ЮKassa один в один,
боевой режим включается сам при появлении секретов `YOOKASSA_SHOP_ID` и
`YOOKASSA_SECRET_KEY` — переписывать флоу не нужно.

## Заявки

Формы сайта и сообщения из ВКонтакте идут в **один** поток: Telegram + VK
одновременно. Отвалившийся канал не отменяет второй.

| Маршрут | Что делает |
|---|---|
| `POST /submit` | заявки с форм сайта |
| `POST /create-payment` | считает сумму, создаёт платёж |
| `POST /payment-notification` | вебхук ЮKassa о статусе |
| `ANY /vk-callback` | подтверждение и входящие из VK |
| `GET /catalog` | цены, которыми считает сервер |

## Развернуть

Пошаговая инструкция — в `README-deploy.md` внутри пакета
`site-ready-to-deploy`. Кратко:

```bash
cd api && wrangler deploy
```

Затем вписать выданный адрес в `assets/api.js` и задать секреты
(`wrangler secret put ...`, список в `.env.example`).

Пока `API_BASE` пуст, сайт работает в демо-режиме: формы показывают
подтверждение, оплата идёт по локальной заглушке.

## Перед публикацией

Контакты, адрес студии, цены ярусов и отзывы — демонстрационные.
Замените на настоящие, особенно в блоке JSON-LD в `index.html`:
вымышленные данные в структурированной разметке поисковики считают обманом.
